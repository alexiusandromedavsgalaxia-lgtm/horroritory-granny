# Horroritory Granny

Fan-made original horror escape game for Android APK.

## Modes
- Easy
- Normal
- Hard
- Extreme
- Impossible
- Crazy
- Super Crazy
- AE [❔]

### AE [❔]
The final experimental mode pushes the house into an unstable state: extremely limited visibility, intensified environmental creaks, multiple Granny AI instances, greatly increased enemy movement speed, and rats appearing throughout the house.

## Important
This project uses original code, assets, names, sounds, environments, and characters. It is inspired by the survival-horror escape genre and does not include copyrighted Granny assets or code.
